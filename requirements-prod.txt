# --- GUARDRAILS ---
# Bumped from 0.21.0 2026-09-13: that version's BasicEmbeddingsIndex.build()
# uses Annoy (`from annoy import AnnoyIndex; ... self._index.build(10)`) for
# the canonical-form/flow search index. Annoy's native C++ extension SIGILLs
# (exit 132) on Render's virtualized CPU — 100% reproducible, confirmed via
# faulthandler, on every single guardrail check in a fresh container.
# 0.23.0 replaced Annoy entirely with a pure-numpy cosine-similarity index
# (see nemoguardrails/embeddings/basic.py's build()/search()) — no native ANN
# library at all. This is also the version every local test in this
# deployment used (the working venv's actual installed version throughout),
# so bumping the pin aligns production with what was actually verified,
# rather than the untested original pin. See DEPLOYMENT_REPORT.md.
nemoguardrails==0.23.0
