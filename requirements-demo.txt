# ==============================================================================
# LOCAL DEMO REQUIREMENTS — the minimum to run the chat demo end to end.
#
# Excluded relative to requirements.txt:
#   ragas, pandas, nest-asyncio   → eval dashboard only
#   unstructured                  → .docx/.pptx now parse via python-docx and
#                                   python-pptx; unstructured is only needed for
#                                   other office formats
#   pdfplumber                    → per-page PDF fallback; DATA/true_data has no PDFs
#   langchain-google-genai        → Gemini embeddings, cloud mode only
#   pytest                        → tests
#
# ------------------------------------------------------------------------------
# IMPORTANT — install CPU-only PyTorch FIRST, or pip will pull the CUDA build
# (~2.5 GB on Windows) as a dependency of sentence-transformers:
#
#     pip install torch --index-url https://download.pytorch.org/whl/cpu
#     pip install -r requirements-demo.txt
#
# The CPU wheel is roughly 200 MB. Nothing here uses a GPU — the reranker runs
# ONNX on CPU and embeddings are small enough that it makes no difference.
# ==============================================================================
